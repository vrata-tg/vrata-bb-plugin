# Врата AI для bb

Плагин добавляет в bb провайдер **Врата AI (Pi)** со встроенным рантаймом Pi agent. Отдельные CLI агенты устанавливать не нужно. Pi запускается внутри плагина, видит файлы проекта и использует инструменты чтения, редактирования и командной строки для моделей, которые поддерживают инструменты.

## Установка

```bash
bb plugin install git:https://github.com/v-lebedev/vrata-bb-plugin
```

В новом треде выберите провайдер **Врата AI (Pi)** и модель **Авто · Врата AI**. Отправьте запрос. Если ключ ещё не сохранён, в треде появится поле для него. После проверки ключа тот же запрос продолжится автоматически. Получить ключ можно через [бот Врата AI](https://vrata.tg/bot).

Ключ хранится в секретных настройках bb и передаётся рантайму на машине треда через файл с правами `0600`. В истории треда сохраняется только факт завершения настройки, без значения ключа. Ключ также можно задать заранее в настройках плагина.

После настройки плагин получает доступные для ключа модели из `GET /v1/models`. Модель **Авто** выбирает доступную модель с инструментами, если такая есть. Каталог моделей bb может сохраняться в кеше; **Авто** работает сразу после ввода ключа. В настройках плагина можно поменять адрес API; по умолчанию используется `https://api.vrata.tg`.

## Разработка

```bash
npm ci
npm run typecheck
npm run build
npm test
```

Тест запускает встроенный bridge и локальный имитатор API: проверяет запрос ключа в треде, продолжение первого запроса, потоковый ответ и восстановление сессии. Реальный ключ для него не нужен.
