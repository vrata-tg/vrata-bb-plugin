# Врата AI для bb

Плагин добавляет в bb провайдер **Врата AI (Pi)** со встроенным рантаймом Pi agent. Отдельные CLI агенты устанавливать не нужно. Pi запускается внутри плагина, видит файлы проекта и использует инструменты чтения, редактирования и командной строки для моделей, которые поддерживают инструменты.

## Установка

```bash
bb plugin install git:https://github.com/v-lebedev/vrata-bb-plugin
```

В новом треде выберите провайдер **Врата AI (Pi)**. Если ключ ещё не сохранён, выберите **Ввести ключ и выбрать модель** и отправьте запрос. В треде появятся форма для ключа и список доступных моделей. Выберите модель и уровень ризонинга; исходный запрос продолжится автоматически. Получить ключ можно через [бот Врата AI](https://vrata.tg/bot).

Ключ хранится в секретных настройках bb и передаётся рантайму на машине треда через файл с правами `0600`. В истории треда сохраняется только факт завершения настройки, без значения ключа. Ключ также можно задать заранее в настройках плагина.

После настройки плагин получает доступные для ключа модели из `GET /v1/models` и показывает их в обычном переключателе моделей bb. Список уровней ризонинга зависит от модели и выбранного API: Pi передаёт поддерживаемые уровни, включая `xhigh` и `max`, когда они доступны. Для остальных моделей доступен только «Выкл.». Когда каталог Врата AI возвращает `gateway_metadata.supports_reasoning`, плагин использует этот признак; для старого API он использует сведения встроенного каталога Pi, когда узнаёт модель по ID. В настройках плагина можно поменять адрес API; по умолчанию используется `https://api.vrata.tg`.

Подтверждение настройки ждёт записи ключа именно на машину текущего треда. Изменения ключа и адреса API применяются вместе со следующего хода. Модель, уровень ризонинга и история сохраняются для восстановления сессии.

## Работа в треде

Можно прикладывать текстовые файлы UTF-8 и изображения PNG, JPEG, GIF, WebP. Изображения требуют модели с поддержкой vision; большие изображения автоматически уменьшаются. Неподдерживаемые вложения завершают ход с понятной ошибкой. Обработка изображений встроена в `host.js` и не требует отдельных файлов WASM на машине треда.

Для моделей с инструментами доступны штатные coding tools Pi и dynamic tools, переданные bb, с учётом списка запрещённых инструментов. Тред показывает текст ответа, рассуждения, результаты инструментов и расход токенов. Во время генерации можно направить дополнительное сообщение через steer. При остановке текущие сообщения сохраняются; после interrupt можно продолжить тред.

Перед каждым обращением к модели, включая продолжения после инструментов, плагин оценивает размер контекста с учётом инструкций, схем инструментов и резерва ответа. При достижении лимита ход завершается ошибкой, история сохраняется. Оценка приблизительная; автоматического сжатия истории нет. Платные запросы не перенаправляются и не повторяются автоматически.

Поддерживается режим разрешений `full`. Fork, ручное сжатие контекста, архивирование и переименование тредов средствами провайдера, native user questions и service tier пока недоступны. Наличие модели в каталоге не гарантирует корректную работу инструментов у её upstream-провайдера.

## Баланс

Внизу левой панели bb отображается общий баланс аккаунта Врата AI в рублях, включая бонусы и средства в резерве (доступная сумма плюс резерв). При наведении отдельно показаны доступная сумма, оплаченные средства, бонусы, резерв и время проверки. Баланс обновляется после завершения каждого запроса к Вратам (включая ошибки), а при отсутствии запросов — каждые 30 секунд. Также его можно обновить нажатием или возвратом в окно. Рядом кнопка **Пополнить** открывает [бота Врата AI](https://vrata.tg/bot) в новой вкладке. Без ключа строка скрыта; при ошибке вместо суммы отображается «Баланс недоступен». Запрос `GET /v1/account` выполняется на сервере bb с сохранённым ключом.

## Разработка

Правила разработки: [AGENTS.md](AGENTS.md). Полный процесс планирования,
реализации, ревью и доставки через PR:
[vrata-bb-plugin-dev](.agents/skills/vrata-bb-plugin-dev/SKILL.md).

```bash
npm ci
npm run typecheck
npm run build
npm test
```

Тесты используют синтетические ключи, локальные HTTP-серверы и SDK harness. Они проверяют баланс, onboarding целевой машины, транспорт и уровни ризонинга, отмену и восстановление, вложения, dynamic tools, события и ограничения контекста. Отдельная проверка запускает единственный собранный `host.js` из временной директории и читает изображения. Реальный ключ не нужен.

В [packaging/NOTICE.md](packaging/NOTICE.md) описаны встроенные компоненты обработки изображений и их воспроизводимое обновление.
