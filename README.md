# Врата AI для bb

Плагин добавляет в bb провайдер **Врата AI (Pi)** со встроенным полноценным **Pi 1.3.0**. Отдельный CLI устанавливать не нужно. Сессии, инструменты, повторы и сжатие контекста выполняет штатный Pi; плагин связывает его с BB. Нужны bb 0.41+ и Node.js 22.19.0+.

## Установка

```bash
bb plugin install npm:@vrata-ai/bb-plugin
```

## Подключение

Откройте **Подключить Врата AI** в сайдбаре или нажмите **Добавить ключ Врата AI**
на месте баланса. Получите ключ в [боте Врата AI](https://vrata.tg/bot), вставьте
его в поле **Ключ API** и нажмите **Сохранить ключ**. При необходимости измените
адрес API. Если подключено несколько машин, выберите нужную: ключ хранится только
на машине выполнения запросов и не переносится на другие машины.

Также можно сразу выбрать провайдер **Врата AI (Pi)** и отправить первое
сообщение: в треде появится форма ключа, затем выбор модели и уровня рассуждений.
После настройки исходный запрос продолжится автоматически. Ключ можно заменить
или удалить в настройках плагина.
