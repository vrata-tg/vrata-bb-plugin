# Врата AI для bb

Плагин добавляет в bb провайдер **Врата AI** со встроенным полноценным **Pi 1.3.0**. Отдельный CLI устанавливать не нужно. Сессии, инструменты, повторы и сжатие контекста выполняет штатный Pi; плагин связывает его с BB. Нужны bb 0.41+ и Node.js 22.19.0+.

## Установка

```bash
bb plugin install npm:@vrata-ai/bb-plugin
```

Добавьте ключ на странице Врата AI, затем выберите модель и уровень рассуждений
в штатном меню bb рядом с полем ввода. Отдельного диалога выбора модели нет.
Каталог загружается с API для компьютера, на котором выполняется тред.

Настройка ключа открывается по явному действию и не перенаправляет из треда автоматически.
