# Врата AI для bb

Плагин добавляет в bb провайдер **Врата AI (Pi)** со встроенным рантаймом Pi agent. Отдельные CLI агенты устанавливать не нужно. Pi запускается внутри плагина, видит файлы проекта и использует инструменты чтения, редактирования и командной строки для моделей, которые поддерживают инструменты.

## Установка

```bash
bb plugin install git:https://github.com/v-lebedev/vrata-bb-plugin
```

В новом треде выберите провайдер **Врата AI (Pi)**. Если ключ ещё не сохранён, выберите **Ввести ключ и выбрать модель** и отправьте запрос. В треде появятся форма для ключа и список доступных моделей. Выберите модель и уровень ризонинга; исходный запрос продолжится автоматически. Получить ключ можно через [бот Врата AI](https://vrata.tg/bot).

Ключ хранится в секретных настройках bb и передаётся рантайму на машине треда через файл с правами `0600`. В истории треда сохраняется только факт завершения настройки, без значения ключа. Ключ также можно задать заранее в настройках плагина.

После настройки плагин получает доступные для ключа модели из `GET /v1/models` и показывает их в обычном переключателе моделей bb. Для моделей с поддержкой ризонинга доступны уровни от «Выкл.» до «Максимальный»; выбранный уровень передаётся Pi при каждом запросе. Для остальных моделей доступен только «Выкл.». Когда каталог Врата AI возвращает `gateway_metadata.supports_reasoning`, плагин использует этот признак; для старого API он использует сведения встроенного каталога Pi, когда узнаёт модель по ID. В настройках плагина можно поменять адрес API; по умолчанию используется `https://api.vrata.tg`.

## Разработка

```bash
npm ci
npm run typecheck
npm run build
npm test
```

Тест запускает встроенный bridge и локальный имитатор API: проверяет запрос ключа и выбор модели в треде, передачу уровня ризонинга, потоковый ответ и восстановление сессии. Реальный ключ для него не нужен.
