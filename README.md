# Врата AI для bb

Плагин добавляет в bb провайдер **Врата AI** со встроенным полноценным **Pi 1.3.0**. Отдельный CLI устанавливать не нужно. Сессии, инструменты, повторы и сжатие контекста выполняет штатный Pi; плагин связывает его с BB. Нужны bb 0.41+ и Node.js 22.19.0+.

## Установка

```bash
bb plugin install npm:@vrata-ai/bb-plugin
```

## Модели

Список моделей, транспорт, цены и лимиты загружаются из API Врата AI для вашего ключа. Добавление модели или изменение этих данных на сервере не требует обновления плагина. Поддержка инструментов и изображений учитывается из каталога; модели с явно отключёнными инструментами не предлагаются для кодинга.

Карты уровней reasoning и особенности Anthropic берутся из встроенного Pi, поскольку API пока не публикует эти данные. Для каталогов без дополнительных метаданных сохраняются общие значения: контекст 128 000, ответ до 16 384 токенов, неизвестная стоимость — 0, поддержка изображений — как прежде. Цены каталога RUB/token переводятся в ставки за миллион токенов для Pi.
