# Врата AI для bb

Плагин добавляет в bb провайдер **Врата AI** со встроенным полноценным **Pi 1.3.0**. Отдельный CLI устанавливать не нужно. Сессии, инструменты, повторы и сжатие контекста выполняет штатный Pi; плагин связывает его с BB. Нужны bb 0.41+ и Node.js 22.19.0+.

## Установка

Запросы к API отправляют `User-Agent` вида `vrata-bb-plugin/<версия плагина> bb/<версия bb> (<ОС> <версия ОС>; <архитектура>)`. В сборке форка Врата первым продуктом будет `vrata-bb/<версия bb>`, затем `vrata-bb-plugin/<версия плагина>`. Версия bb относится к серверу; ОС, её версия и архитектура — к машине, выполняющей запрос.

```bash
bb plugin install npm:@vrata-ai/bb-plugin
```
